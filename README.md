# CodeAlpha - Matrix Operations in C

This project was developed as part of the **CodeAlpha Internship Program**.  
It implements essential matrix operations using the C programming language, focusing on dynamic memory management and safe user input handling.

## Features
- Safe integer input validation  
- Dynamic matrix allocation and deallocation  
- Matrix addition  
- Matrix multiplication  
- Matrix transpose  
- Clear error handling and user prompts  

## How to Run
```bash
gcc MatrixOperations.c -o MatrixOperations
./MatrixOperations
